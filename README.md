# TRPG Assistant Tool

A simple Python tool for TRPG keepers and tabletop RPG management.

## Features

- Roll dice
- Add NPC data
- View NPC list
- View full NPC detail
- Search NPC
- Delete NPC
- Save data with JSON

## Technologies

- Python
- JSON
- File handling

## How to Run

```bash
python trpg_assistant.py
```
